# DailyFlow Product Overview

## Product Vision

DailyFlow is a personal productivity application designed to help users manage their daily work, remember important activities, build consistent habits, and understand their overall productivity.

The application combines task management, reminders, habit tracking, and productivity analytics into a single unified experience.

## Target Users

DailyFlow is designed for individuals who want to:

- Organize their daily tasks
- Track work progress
- Set reminders for important activities
- Build and maintain productive habits
- Monitor their productivity over time

## Core Features

### 1. Task Management

Users can:

- Create tasks
- View tasks on a Kanban board
- Move tasks between Todo, In Progress, and Done
- Track task completion

### 2. Reminder Management

Users can:

- Create reminders
- Set reminder schedules
- Create daily recurring reminders
- Create weekly recurring reminders
- Acknowledge completed reminders

### 3. Habit Tracking

Users can:

- Create habits
- Record daily habit completion
- Track consecutive completion streaks
- View their habit consistency

### 4. Productivity Score

DailyFlow calculates a productivity score using data from tasks, reminders, and habits.

The score is calculated using:

- Task Completion Rate: 40%
- Reminder Acknowledgement Rate: 30%
- Habit Streak Consistency: 30%

## Data Relationship

All DailyFlow modules are connected through a shared User entity.

A user can have:

- Multiple tasks
- Multiple reminders
- Multiple habits
- One calculated productivity score

## Product Goals

DailyFlow should provide a simple, reliable, and easy-to-use productivity management experience.

The system should:

- Keep data organized
- Provide accurate productivity calculations
- Track user activity consistently
- Support data export
- Present productivity information clearly
